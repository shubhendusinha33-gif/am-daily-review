Email Setup (ZFM Alerts)

Uses EmailJS (free, 200 emails/month). Setup takes 5 min:

1. Go to emailjs.com → Sign Up Free
2. Add Service → Gmail → connect your email
3. Create Template → name it vmm_zfm_alert
4. In template body paste the HTML from the box below
5. Set "To Email" field to {{to_email}}
6. Copy Service ID, Template ID, Public Key → paste below
📋 Copy this as your EmailJS template body:
Dear ZFM, AM Daily Review submitted. Store: {{store_code}} - {{store_name}} AM: {{am_name}} Date: {{review_date}} Compliance: {{compliance_pct}}% SECTION RESULTS: {{sections_html}} Remarks: {{remarks_summary}} This is an automated alert from VMM AM Daily Review.
